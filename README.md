# 📘 Projectos em C

Este repositório contém uma coleção de projetos e exercícios desenvolvidos em **linguagem C**, com foco em reforçar os fundamentos da programação estruturada e o uso correto de memória, ponteiros e ficheiros.

O objetivo é **aprendizado prático**, organização de estudos e construção de um portfólio sólido em C.

---

## 📚 Conteúdos abordados

- 📂 Manipulação de ficheiros (binários e texto)
- 👉 Ponteiros e endereçamento de memória
- 🔢 Arrays e estruturas
- ⚙️ Entrada e saída padrão
- 🧠 Lógica de programação em C
- 🛠️ Uso de `fopen`, `fread`, `fwrite`, `fseek`, `ftell`, etc.
